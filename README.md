# LOCAL-CONTACT

مستودع لمشروع أندرويد بلغة Kotlin لمشاركة الملفات، الفيديوهات، الصوت، الرسائل والمكالمات الصوتية كمجموعة أو منفردًا دون اتصال بالإنترنت.

## الوصف

التطبيق يهدف إلى تمكين المستخدمين من:
- مشاركة الملفات (صور، مستندات، فيديو) بدون إنترنت عبر الاتصال المباشر (مثل Wi‑Fi Direct أو Bluetooth).
- إرسال واستقبال الرسائل النصية داخل المجموعة أو بشكل فردي.
- إرسال مقاطع صوتية ومكالمات صوتية محلية.

> الوصف الوارد في صفحة المستودع: "Sharing  file  vidoes  audio  voise   and message as group  and alone off line"

## المميزات

- مكتوب بالكامل بلغة Kotlin.
- مشاركة ملفات وصيغ وسائط متعددة.
- دعم للمحادثات الجماعية والفردية.

## المتطلبات

- Android Studio (آخر إصدار مستحسن)
- JDK 11 أو أحدث
- جهاز أندرويد أو محاكي يدعم الاتصال اللاسلكي/البلوتوث

## كيفية التشغيل

1. افتح المشروع في Android Studio.
2. قم بمزامنة Gradle (Sync Project with Gradle Files).
3. قم بتشغيل التطبيق على جهاز أو محاكي.

ملاحظة: إذا كان المشروع يستخدم ميزات الاتصال المباشر مثل Wi‑Fi Direct أو Bluetooth، فقد تحتاج إلى منح أذونات الموقع والبلوتوث على الجهاز.
